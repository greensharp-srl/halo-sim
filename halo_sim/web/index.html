Halo SIM

This device becomes the glasses: its camera, microphone, motion sensors and speaker feed the virtual Halo, and the round display shows what the glasses draw.

Camera and microphone need a secure (HTTPS) page.

  1. Download and install the local certificate: halo-sim-ca.crt
  2. iPhone: Settings → General → VPN & Device Management → install the profile, then Settings → General → About → Certificate Trust Settings → enable “Halo SIM Local CA”.
    Android: Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
  3. Open the secure page.

Desktop keys: Space click · D double · L long · T tap · 2 double tap · 3 triple tap
